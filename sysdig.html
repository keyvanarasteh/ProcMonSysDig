System Backend Setup Guide

Bu panel tek başına (frontend olarak) çalışmaktadır. Sisteminizi izlemek ve bu paneli bağlamak için arka planda Linux kayıt araçlarını (Procmon / Sysdig) kurmanız gerekmektedir.

⚡ 1-Click Automated Setup (Tavsiye Edilir)

Aşağıdaki manuel adımlarla uğraşmak yerine, arka uç köprüsü üzerinden her şeyi doğrudan panelden otomatik kurun.


            

            

            

                
1. Sysdig ve Kernel Başlıklarını Kurma

                
Eğer sadece `sysdig` komutunu kurarak basit bir socket başlatacaksanız, doğrudan apt depolarını kullanabilirsiniz:

                
sudo apt-get update
sudo apt-get install sysdig linux-headers-$(uname -r)

            


            

                
2. Microsoft Procmon Kurulumu (Manuel Deb)

                
Kali Linux / Debian 12 repolarında SHA1 doğrulama sorunu yaşandığı için Procmon ve eBPF kütüphanesi doğrudan Microsoft'tan indirilip kurulmalıdır.

                
# 1. sysinternalsebpf bağımlılığını kur  
wget -O sysinternalsebpf.deb https://packages.microsoft.com/debian/12/prod/pool/main/s/sysinternalsebpf/sysinternalsebpf_1.5.0_amd64.deb
sudo dpkg -i sysinternalsebpf.deb

# 2. procmon'u kur
wget -O procmon.deb https://packages.microsoft.com/debian/12/prod/pool/main/p/procmon/procmon_2.2.0_amd64.deb
sudo dpkg -i procmon.deb
sudo dpkg --configure procmon
rm procmon.deb sysinternalsebpf.deb

            


            

                
3. WebSocket Bridge (Örnek Node.js Yaklaşımı)

                
Sistemi dinleyip bu HTML paneline veri yollamak için bir bridge scriptine ihtiyacınız vardır. Aşağıdaki örnek yapı kullanılabilir:

                
// backend.js (Kurulum tamamlanınca örnektir)
const { spawn } = require('child_process');
const sysdig = spawn('sysdig', ['-j']); // JSON çıktısı verir
// WebSocket ile bu panele fırlatın...
